# Post title tags (`meta_title`)

**Layer:** post `meta_title` (the `<title>` and `og:title`). Not the H1: each post keeps its own headline.

**Status:** approved by the owner 3 Oct 2026 (audit I18); live. The old tags read as keyword strings (“Holiday Backup Plan Care Worker Change”). These keep each post's search phrase near the front, in plain sentence case, 40–60 characters, matching how the page titles are written. Applied in `inc/seo-content-seed-blog-priority.php` (the seeder) and `inc/seo-content-seed-meta.php`; migrations v71 and v73 update stored tags only where they still hold the old keyword string, so a hand-edited tag is left alone.
