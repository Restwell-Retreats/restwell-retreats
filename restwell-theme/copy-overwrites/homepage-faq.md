# Homepage FAQ

**Layer:** `inc/homepage-faq.php` via `restwell_get_faq_items( 'homepage' )`. The same three pairs must appear on the visible accordion and in the FAQPage JSON-LD.

Guest copy lives in `home.md`. Use those three questions exactly as written there. Don’t maintain a second version here, and don’t let the schema drift from what a visitor can see on the page.

The three are:

1. Is Restwell a care home?
2. Will a wheelchair actually fit?
3. Can we add home care?

They’re chosen because they’re the three objections that stop an enquiry, in the order people think of them. Each answer opens with a direct yes or no, which is both what a worried reader wants and what an AI answer engine can quote without paraphrasing us.

The full FAQ page carries the longer list → `/faq/`

Walk time still doesn’t belong in these three: it isn’t an objection that stops an enquiry. It now has a real answer on `/faq/` and `/whitstable-area-guide/`: about ten minutes to the seafront, longer for anywhere along the promenade.
