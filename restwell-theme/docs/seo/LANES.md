# SEO lanes

One primary keyphrase per indexable URL. Other pages may mention the topic; they link to the owner.

Primaries below match `focus_keyphrase` in [`inc/seo-content-seed-meta.php`](../../inc/seo-content-seed-meta.php). Update that file if you change a lane.

**Language (2026-08-13):** “respite” and “wheelchair friendly” are allowed in copy, titles, and metas. Never use “fully accessible”. Do not describe Restwell as a care home or respite centre. Wheelchair-friendly claims sit next to millimetres and kit, not instead of them.

## Quick conflict checks

1. Home vs Accessibility — Home = Whitstable holidays category; Accessibility = cottage **specs**, not a second holidays landing.
2. Property vs Accessibility — Property = tour + book; Accessibility = measurements + kit.
3. Pricing vs Resources — Pricing = £; Resources = who pays / paperwork.
4. Whitstable guide vs beach/parking posts — guide = hub; posts = one narrow angle each.
5. Website accessibility policy ≠ property `/accessibility/`.
